# Answers

## 1. Frontend Stack

I used React with Vite and Tailwind CSS.

## 2. Validation Strategy

Inline validation messages are shown beside fields instead of browser alerts.

## 3. Live Updates

Calculations update instantly while typing without requiring a calculate button.

## 4. Edge Cases

The app handles negative numbers, zero people, invalid input, and large values gracefully.

## 5. Rounding Policy

Per-person values are rounded up to 2 decimal places to ensure the total bill is never underpaid.
